1. Aporte realizado
Describir brevemente las actividades realizadas durante esta etapa.

Definición e implementación completa del script DDL para la creación de la base de datos FarmaBlue y la estructura de sus tablas principales con sus respectivas restricciones de clave primaria (PRIMARY KEY), clave foránea (FOREIGN KEY), unicidad (UNIQUE) y verificación (CHECK).

Elaboración e implementación del script DML para la carga inicial de datos ficticios pero coherentes con el dominio del problema (10 registros por tabla).

Organización y estructuración de los scripts SQL dentro del repositorio de GitHub respetando la jerarquía de carpetas requerida por la cátedra (sql/ddl/ y sql/dml/).

2. Decisiones en las que participé
Indicar decisiones relacionadas con el dominio, alcance o reglas de negocio.

Ajuste del tipo de dato del campo telefono en la tabla cliente pasando de tipo entero (INT) a alfanumérico (VARCHAR(20)), evitando desbordamiento numérico para códigos de área/números de 10 dígitos y preservando el cero inicial.

Establecimiento de las políticas de integridad referencial para el manejo de borrado y actualización de claves foráneas (ON DELETE NO ACTION ON UPDATE CASCADE), garantizando la preservación del historial de ventas/compras y evitando la presencia de datos huérfanos.

Definición de los límites de datos y valores por defecto para el control de crédito (limite_credito), stock disponible (stock_disponible >= 0) y atributos de control sanitario para productos psicotrópicos y con cadena de frío.

3. Problemas o dificultades identificadas
Describir dificultades encontradas durante el desarrollo.

Incompatibilidad de tipos de datos: El tipo de dato INT inicialmente propuesto para teléfonos resultaba insuficiente para almacenar identificadores telefónicos completos con característica regional.



4. Soluciones o propuestas realizadas
Explicar brevemente cómo se resolvieron o propusieron resolver las dificultades.

Se corrigió el tipo de dato de la columna telefono a VARCHAR(20) en la definición de la tabla cliente.
