Trazabilidad estricta de medicamentos vía Lotes: Se decidió desvincular la venta directa del Producto e interponer la entidad lote en detalle_venta,
asegurando el control estricto de la fecha de vencimiento y el stock disponible por lote de origen.

Reglas de negocio e integridad en el cliente: Inclusión del campo autorizacion_psicotropico y datos de habilitación sanitaria (matricula_habilitacion_sanitaria, 
fecha_vencimiento_habilitacion) para restringir la venta de medicamentos controlados a entidades autorizadas.

Desvinculación del catálogo respecto a compras y ventas: El catálogo de productos actúa como entidad central compartida entre los proveedores (compra / detalle_compra) y el inventario disponible (lote / detalle_venta).

3. Problemas o dificultades identificadas
Describir dificultades encontradas durante el desarrollo.

Gestión de la integridad referencial cíclica o en cascada: Dificultad para definir la estrategia de borrado/actualización de claves foráneas
(ON DELETE NO ACTION vs ON DELETE CASCADE) sin generar conflictos de eliminación en cascada circular entre clientes, ventas, lotes y productos.

Coherencia y consistencia de datos numéricos DML: Desafío al calcular manualmente montos de subtotal, descuentos, impuestos (IVA 21%) 
y montos totales en la tabla venta para que coincidan numéricamente con los registros de detalle_venta.

4. Soluciones o propuestas realizadas
Explicar brevemente cómo se resolvieron o propusieron resolver las dificultades.

Configuración segura de FK: Se optó de manera preventiva por utilizar ON DELETE NO ACTION junto con ON UPDATE CASCADE 
en todas las relaciones para proteger la persistencia de datos históricos (evitando que al borrar un cliente o producto se elimine su historial de ventas o compras).

Validación de consistencia DML: Se utilizaron scripts complementarios de verificación mediante sentencias SELECT con JOIN y agregaciones (SUM) 
para corroborar que los totales de la tabla venta reflejaran exactamente el cálculo de cantidad * precio_unitario_historico de sus detalles.
