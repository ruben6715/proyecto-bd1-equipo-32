# Manifiesto Individual - Valentino Greatti

## 1. Aporte realizado

Durante el desarrollo del proyecto de bases de datos de FarmaBlue, contribuí al análisis de la información y a la elaboración de consultas SQL para facilitar la gestión de las ventas y los productos de la droguería.

Mi aporte se centró en comprender cómo se organiza la información dentro de la base de datos y cómo utilizarla para obtener resultados útiles. También trabajé en la construcción de consultas que permiten relacionar los datos de distintas tablas y presentar la información de manera ordenada, facilitando su interpretación.

## 2. Decisiones en las que participé

Participé en el análisis de las relaciones entre las tablas, teniendo en cuenta la importancia de mantener la información correctamente vinculada y evitar resultados incorrectos al combinar datos.

Además, consideré la utilización de filtros y agrupaciones para obtener información específica de las ventas, los productos y los clientes. Estas decisiones permiten que las consultas respondan a las necesidades del negocio y que los resultados sean más claros y útiles.

## 3. Problemas o dificultades identificadas

Una de las dificultades encontradas durante el desarrollo fue comprender cómo combinar correctamente las consultas SQL con las relaciones entre diferentes tablas.

También surgieron dudas al trabajar con funciones de agregación, como `SUM()` y `COUNT()`, especialmente al momento de agrupar los resultados mediante `GROUP BY` y establecer condiciones sobre los datos agrupados con `HAVING`.

## 4. Soluciones o propuestas realizadas

Para resolver estas dificultades, revisé la estructura de las consultas y la función de cada cláusula de SQL, buscando comprender cómo se relacionan entre sí.

También reforcé el uso de las relaciones entre tablas y las funciones de agrupación, realizando correcciones para mejorar la organización y la precisión de los resultados obtenidos.

Estas mejoras permitieron comprender mejor el funcionamiento de las consultas y la importancia de verificar los resultados antes de utilizarlos en los reportes del sistema.
